# Power Grid Manager — Steam Changelog

## 1.0.1 — Heatmap Performance

- Reduced the work needed to display the Heatmap, especially in colonies with many powered buildings. This update targets FPS drops while the Heatmap is open.
- Fixed the Heatmap scrolling beyond the available results when a search or a change in buildings makes the list shorter.
- Heatmap modes, search, building selection, tooltips, Locate, and Inspect remain available.
- This update does not change your colony's power simulation or save data.

## 1.0.0 — RimWorld 1.5 and 1.7 Compatibility

- Fixed missing mod files for RimWorld 1.5 and 1.7.
